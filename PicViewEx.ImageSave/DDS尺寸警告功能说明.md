# DDS尺寸警告功能优化说明

## 概述
优化了DDS格式保存时的尺寸警告功能，将原有的简单MessageBox替换为功能丰富的专用窗口，并增加了智能缩放到2的幂次方的功能。

## 主要改动

### 1. 新增文件
- **DdsResizeWarningWindow.xaml**: 新的DDS尺寸警告窗口界面
- **DdsResizeWarningWindow.xaml.cs**: 窗口后端逻辑，包含推荐分辨率计算和图像缩放功能

### 2. 修改文件
- **SaveAsWindow.xaml.cs**: 
  - 将两处MessageBox警告替换为新的DdsResizeWarningWindow
  - 支持在警告后进行图像缩放
  
- **IImageSaver.cs**:
  - 给SaveResult类添加了IsCancelled属性，用于区分用户取消和保存错误

## 功能特性

### 1. 智能推荐分辨率
- **推荐规则**：基于游戏行业标准（16, 32, 64, 128, 256, 512, 1024, 2048）
- **推荐逻辑**：
  - 找到图片的最长边
  - 找最接近的2的幂次方尺寸
  - 一般放大不缩小（除非超过2048）
  - 最大推荐值为2048×2048
  - 推荐值统一为正方形纹理

### 2. 丰富的分辨率选项
窗口提供了完整的分辨率列表，包括：
- **正方形纹理**：从16×16到4096×4096
- **非正方形纹理**：常用的宽屏、竖屏、超宽、超高比例
- 最大支持到4096×4096

### 3. 用户友好的界面
- 显示当前图像尺寸和警告信息
- 推荐分辨率在列表最上方显示，带【推荐】标识
- 每个分辨率选项显示缩放比例（放大/缩小）
- 三个操作按钮：
  - **缩放并继续**：将图像缩放到选定分辨率后继续保存
  - **直接继续**：忽略警告，使用原始尺寸保存
  - **取消**：取消保存操作

### 4. 推荐算法示例
- 原始尺寸 1142×2 → 推荐 2048×2048（最长边1142，超过1024，推荐2048）
- 原始尺寸 998×2 → 推荐 1024×1024（最长边998，小于1024，推荐1024）
- 原始尺寸 2500×3 → 推荐 2048×2048（最长边2500，超过2048，限制为2048）
- 原始尺寸 300×400 → 推荐 512×512（最长边400，推荐512）

### 5. 取消操作优化
- **修复前**：点击取消会弹出错误对话框，影响用户体验
- **修复后**：点击取消时静默返回，不再显示错误对话框

## 技术实现

### 推荐分辨率计算
```csharp
private (int width, int height) CalculateRecommendedResolution(int width, int height)
{
    int maxDimension = Math.Max(width, height);
    
    // 如果超过2048，推荐2048×2048
    if (maxDimension > 2048)
        return (2048, 2048);
    
    // 找到最接近的游戏纹理尺寸（向上取整）
    int[] sizes = { 16, 32, 64, 128, 256, 512, 1024, 2048 };
    foreach (int size in sizes)
    {
        if (size >= maxDimension)
            return (size, size);
    }
    
    return (2048, 2048);
}
```

### 图像缩放
使用WPF的TransformedBitmap进行高质量缩放：
```csharp
var scaledBitmap = new TransformedBitmap(source,
    new ScaleTransform(
        (double)targetWidth / source.PixelWidth,
        (double)targetHeight / source.PixelHeight));
```

## 使用流程

1. 用户选择保存为DDS格式
2. 系统检测图像尺寸是否为2的幂次方
3. 如果不是，弹出DdsResizeWarningWindow
4. 窗口显示当前尺寸、警告信息和推荐分辨率
5. 用户可以选择：
   - 选择推荐或其他分辨率，点击"缩放并继续"
   - 点击"直接继续"使用原始尺寸
   - 点击"取消"放弃保存
6. 如果选择缩放，图像会先缩放到目标尺寸再保存

## 兼容性
- 完全向后兼容
- 不影响已有的DDS保存流程
- 所有原有功能（预设、复用参数等）正常工作

3. **更灵活**：支持多种分辨率选择，包括非正方形
