# DDS尺寸警告功能优化说明

## 概述
优化了DDS格式保存时的尺寸警告功能，将原有的简单MessageBox替换为功能丰富的专用窗口，并增加了智能缩放到2的幂次方的功能。

3. **按钮文字优化**："缩放并继续"→"缩放并保存"，"直接继续"→"保存原始分辨率"

## 功能特性

### 1. 双重智能推荐分辨率

#### 正方形推荐
- **推荐规则**：基于游戏行业标准（16, 32, 64, 128, 256, 512, 1024, 2048）
- **推荐逻辑**：
  - 找到图片的最长边
  - 找最接近的2的幂次方尺寸
  - 一般放大不缩小（除非超过2048）
  - 最大推荐值为2048×2048
  - 推荐值统一为正方形纹理

#### 非正方形推荐（新增✨）
- **推荐规则**：保持原图宽高比
- **推荐逻辑**：
  - 分别为长边和短边找最接近的2的幂次方
  - 保持原始图片的方向（横向/竖向）
  - 如果长边和短边推荐相同，短边自动降一级
  - 最大到4096×4096
  - 更贴合原图比例，减少变形

### 2. 丰富的分辨率选项
窗口提供了完整的分辨率列表，包括：
- **正方形纹理**：从16×16到4096×4096
- **非正方形纹理**：常用的宽屏、竖屏、超宽、超高比例
- 最大支持到4096×4096

### 3. 用户友好的界面
- **窗口尺寸**：650×650，更大更方便观看
- 显示当前图像尺寸和警告信息
- **双重推荐**：在列表最上方显示两个推荐项
  - 【推荐 - 正方形】：适合通用游戏纹理
  - 【推荐 - 非正方形】：保持原图比例
- 支持鼠标滚轮滚动查看所有分辨率选项
- 每个分辨率选项显示缩放比例（↑放大 / ↓缩小）
- 三个操作按钮：
  - **缩放并保存**：将图像缩放到选定分辨率后保存
  - **保存原始分辨率**：忽略警告，使用原始尺寸保存
  - **取消**：取消保存操作

### 4. 推荐算法示例

#### 正方形推荐示例
- 原始尺寸 1142×2 → 推荐 2048×2048（最长边1142，超过1024，推荐2048）
- 原始尺寸 998×2 → 推荐 1024×1024（最长边998，小于1024，推荐1024）
- 原始尺寸 2500×3 → 推荐 2048×2048（最长边2500，超过2048，限制为2048）
- 原始尺寸 300×400 → 推荐 512×512（最长边400，推荐512）

#### 非正方形推荐示例
- 原始尺寸 1142×200 → 推荐 2048×256（长边2048，短边256，保持横向）
- 原始尺寸 300×900 → 推荐 512×1024（短边512，长边1024，保持竖向）
- 原始尺寸 1920×1080 → 推荐 2048×2048（长边2048，短边2048，因两边接近会降级短边）
- 原始尺寸 512×256 → 推荐 512×256（刚好符合，不需要缩放）

### 5. 取消操作优化
- **修复前**：点击取消会弹出错误对话框，影响用户体验
- **修复后**：点击取消时静默返回，不再显示错误对话框

## 技术实现

### 推荐分辨率计算
```csharp
private (int width, int height) CalculateRecommendedResolution(int width, int height)
{
    int maxDimension = Math.Max(width, height);
    
    // 如果超过2048，推荐2048×2048
    if (maxDimension > 2048)
        return (2048, 2048);
    
    // 找到最接近的游戏纹理尺寸（向上取整）
    int[] sizes = { 16, 32, 64, 128, 256, 512, 1024, 2048 };
    foreach (int size in sizes)
    {
        if (size >= maxDimension)
            return (size, size);
    }
    
    return (2048, 2048);
}
```

### 图像缩放
使用WPF的TransformedBitmap进行高质量缩放：
```csharp
var scaledBitmap = new TransformedBitmap(source,
    new ScaleTransform(

```

## 使用流程

1. 用户选择保存为DDS格式
2. 系统检测图像尺寸是否为2的幂次方
3. 如果不是，弹出DdsResizeWarningWindow
4. 窗口显示当前尺寸、警告信息和推荐分辨率
5. 用户可以选择：
   - 选择推荐或其他分辨率，点击"缩放并继续"
   - 点击"直接继续"使用原始尺寸
   - 点击"取消"放弃保存
6. 如果选择缩放，图像会先缩放到目标尺寸再保存
