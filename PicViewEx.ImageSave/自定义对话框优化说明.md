# 自定义对话框优化说明

## 更新概述

本次更新将所有系统 MessageBox 对话框替换为美观的自定义对话框，并为保存成功对话框添加了"定位路径"功能。

## 新增文件

### 1. CustomMessageBox（自定义消息框）

**文件：**
- `CustomMessageBox.xaml`
- `CustomMessageBox.xaml.cs`

**功能特点：**
- 美观的深色主题界面，与应用整体风格一致
- 支持多种消息类型：信息、警告、错误、成功
- 每种类型有对应的图标和颜色标识
- 支持多种按钮组合：OK、OK/Cancel、Yes/No、Yes/No/Cancel
- 标题栏可拖动
- 无边框窗口设计，带有彩色边框
- 自动滚动支持，适应长文本消息

**使用示例：**
```csharp
CustomMessageBox.Show(
    "这是消息内容",
    "标题",
    CustomMessageBox.MessageBoxButtons.OK,
    CustomMessageBox.MessageBoxType.Information,
    this);
```

### 2. SuccessDialog（保存成功对话框）

**文件：**
- `SuccessDialog.xaml`
- `SuccessDialog.xaml.cs`

**功能特点：**
- 专门用于显示保存成功的美观对话框
- 显示完整的文件路径（支持换行）
- 显示文件大小和格式信息
- **核心功能：**
  - 📁 **打开文件夹按钮**：使用 Windows Explorer 打开文件夹并自动选中保存的文件
  - 📋 **复制路径按钮**：一键复制文件路径到剪贴板，带有视觉反馈
  - 关闭按钮：关闭对话框
- 绿色主题，突出"成功"状态
- 标题栏可拖动

**使用示例：**
```csharp
SuccessDialog.Show(filePath, this);
```

## 界面设计特点

### 配色方案
- **背景色**：`#FF2D2D30` (深灰色)
- **标题栏**：`#FF1E1E1E` (更深的灰色)
- **按钮默认**：`#FF3E3E42` (中灰色)
- **按钮悬停**：`#FF007ACC` (蓝色)
- **成功主色**：`#FF4CAF50` (绿色)
- **文本颜色**：白色和灰色系

### 图标标识
- ℹ️ 信息 (蓝色)
- ⚠️ 警告 (黄色)
- ❌ 错误 (红色)
- ✅ 成功 (绿色)

## 用户体验改进

### 1. 视觉一致性
- 所有对话框采用统一的深色主题
- 与应用主界面风格保持一致
- 无边框设计更加现代

### 2. 功能增强
- **保存成功后快速定位**：点击"打开文件夹"按钮，自动在资源管理器中打开并选中文件
- **快速复制路径**：点击"复制路径"按钮，立即复制到剪贴板，带有"已复制"反馈
- **详细文件信息**：显示文件大小和格式

### 3. 交互优化
- 所有对话框标题栏可拖动
- 支持键盘快捷键（Enter确认、Esc取消）
- 长文本自动滚动显示
- 按钮有悬停效果

## 技术实现

### 打开文件夹功能
使用 Windows Explorer 的 `/select` 参数：
```csharp
Process.Start("explorer.exe", $"/select,\"{_filePath}\"");
```

### 复制路径功能
使用剪贴板 API：
```csharp
Clipboard.SetText(_filePath);
```

### 自动反馈
复制成功后，按钮文本临时改为"✔️ 已复制"，2秒后恢复。

## 兼容性

- 适用于 Windows 系统
- .NET Framework 4.8
- WPF 应用程序
- 需要 `System.Windows.Forms` 引用（用于剪贴板）

## 注意事项

1. 所有对话框都带有 `Owner` 参数，确保模态显示正确
2. 文件路径显示支持自动换行，适应长路径
3. 错误处理完善，防止路径不存在或无效的情况
4. 按钮操作带有异常捕获和用户反馈
