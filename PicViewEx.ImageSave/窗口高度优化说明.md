# 窗口高度优化说明

## 优化概述

本次更新优化了所有对话框的高度和内部布局，使窗口更加紧凑，不再过长。

## 优化详情

### 1. SaveAsWindow（另存为窗口）

#### 高度优化
- **原高度**：600px
- **新高度**：500px
- **减少**：100px (16.7%)

#### 布局优化
| 元素 | 原值 | 新值 | 说明 |
|------|------|------|------|
| 外边距 | 20px | 15px | 减少外围空间 |
| 标题字号 | 24px | 20px | 更紧凑的标题 |
| 标题间距 | 20px | 12px | 减少标题下方空间 |
| 预览区边距 | 20px | 12px | 压缩预览区间距 |
| 预览区内边距 | 15px | 12px | 减少内部填充 |
| 预览图尺寸 | 200×150 | 180×120 | 更小的预览图 |
| 旋转按钮尺寸 | 120×35 | 110×32 | 更紧凑的按钮 |
| 格式按钮尺寸 | 150×80 | 140×65 | 缩小主要按钮 |
| 格式按钮间距 | 10px | 8px | 减少按钮间距 |

## 建议

如果后续发现窗口内容显示不全或过于拥挤，可以考虑：
1. 调整字体大小
2. 适当增加关键区域的间距
3. 使用可调整大小的窗口（将 `ResizeMode` 改为 `CanResize`）
