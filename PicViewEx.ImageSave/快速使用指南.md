# 保存功能快速使用指南

## 快速上手

### 1. 直接保存（带对话框）✨ 推荐

```csharp
var saver = new ImageSaver();
await saver.SaveWithDialog(bitmapSource, filePath, this);
```

**效果：**
- ✅ 保存到原文件路径
- ✅ 显示成功对话框（文件路径、大小、格式）
- ✅ 提供"打开文件夹"和"复制路径"按钮
- ❌ 保存失败时自动显示错误提示

---

### 2. 另存为（自动选择格式）

```csharp
var saver = new ImageSaver();
await saver.SaveAs(bitmapSource, originalFilePath);
```

**效果：**
- ✅ 打开另存为窗口
- ✅ 用户选择格式和参数
- ✅ 保存成功后显示对话框

---

### 3. 静默保存（不显示对话框）

```csharp
var saver = new ImageSaver();
var result = await saver.Save(bitmapSource, filePath);

// 手动检查结果
if (result.Success)
{
    // 成功处理
}
```

**适用场景：**
- 批量保存
- 自动保存
- 后台保存

---

## 使用对比

| 需求 | 使用方法 |
|------|---------|
| 普通保存（有反馈） | `SaveWithDialog()` ⭐ |
| 另存为 | `SaveAs()` |
| 批量保存（无反馈） | `Save()` |
| 自定义格式保存 | `SaveToWithDialog()` |

---

## 完整示例

```csharp
// 在你的窗口类中
private BitmapSource _currentImage;
private string _currentFilePath;

// 保存按钮
private async void BtnSave_Click(object sender, RoutedEventArgs e)
{
    var saver = new ImageSaver();
    await saver.SaveWithDialog(_currentImage, _currentFilePath, this);
}

// 另存为按钮
private async void BtnSaveAs_Click(object sender, RoutedEventArgs e)
{
    var saver = new ImageSaver();
    await saver.SaveAs(_currentImage, _currentFilePath);
}

// Ctrl+S 快捷键
private async void Window_KeyDown(object sender, KeyEventArgs e)
{
    if (e.Key == Key.S && Keyboard.Modifiers == ModifierKeys.Control)
    {
        var saver = new ImageSaver();
        await saver.SaveWithDialog(_currentImage, _currentFilePath, this);
    }
}
```

## 注意事项

✅ **记得使用 `await`**
```csharp
await saver.SaveWithDialog(...);  // ✅ 正确
saver.SaveWithDialog(...);         // ❌ 错误（对话框可能不显示）
```

✅ **传入父窗口参数**
```csharp
await saver.SaveWithDialog(image, path, this);  // ✅ 对话框居中
await saver.SaveWithDialog(image, path, null);  // ⚠️ 对话框可能在屏幕外
```
