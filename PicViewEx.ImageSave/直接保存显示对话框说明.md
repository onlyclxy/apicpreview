# 直接保存显示成功对话框功能说明

## 概述

现在"直接保存"功能也会显示保存成功对话框，与"另存为"功能保持一致的用户体验。

## 新增文件

### ImageSaverExtensions.cs
这是一个扩展方法类，为 `IImageSaver` 接口添加了带UI反馈的保存方法。

## 核心功能

### 1. SaveWithDialog（直接保存并显示对话框）

```csharp
public static async Task<SaveResult> SaveWithDialog(
    this IImageSaver saver, 
    BitmapSource source, 
    string originalFilePath, 
    Window owner = null)
```

**功能：**
- 调用原有的 `Save` 方法保存图片到原路径
- 如果保存成功，显示 `SuccessDialog`（保存成功对话框）
- 如果保存失败，显示 `CustomMessageBox` 错误提示
- 显示的信息包括：文件路径、文件大小、文件格式

### 2. SaveToWithDialog（保存到指定路径并显示对话框）

```csharp
public static async Task<SaveResult> SaveToWithDialog(
    this IImageSaver saver,
    BitmapSource source,
    string targetPath,
    SaveOptions options,
    Window owner = null)
```

**功能：**
- 调用原有的 `SaveTo` 方法保存图片到指定路径
- 保存成功/失败后显示相应的对话框

## 使用方法

### 方法 1：直接保存（推荐）

使用新的扩展方法 `SaveWithDialog`：

```csharp
// 创建 ImageSaver 实例
var saver = new ImageSaver();

// 直接保存并显示对话框
var result = await saver.SaveWithDialog(bitmapSource, filePath, this);
```

### 方法 2：另存为（已有功能）

使用原有的 `SaveAs` 方法（已经包含对话框）：

```csharp
var saver = new ImageSaver();
var result = await saver.SaveAs(bitmapSource, filePath);
```

### 方法 3：保存到指定路径并显示对话框

```csharp
var saver = new ImageSaver();
var options = new JpegSaveOptions { Quality = 90 };
var result = await saver.SaveToWithDialog(bitmapSource, targetPath, options, this);
```

### 方法 4：不显示对话框（静默保存）

如果某些场景需要静默保存，仍然可以使用原有方法：

```csharp
var saver = new ImageSaver();
var result = await saver.Save(bitmapSource, filePath);
// 不会显示任何对话框，只返回 SaveResult
```

## 完整示例

### 示例 1：保存按钮点击事件

```csharp
private async void BtnSave_Click(object sender, RoutedEventArgs e)
{
    if (_currentImage == null || string.IsNullOrEmpty(_currentFilePath))
    {
        CustomMessageBox.Show(
            "没有可保存的图片！",
            "提示",
            CustomMessageBox.MessageBoxButtons.OK,
            CustomMessageBox.MessageBoxType.Warning,
            this);
        return;
    }

    var saver = new ImageSaver();
    
    // 使用 SaveWithDialog 方法，会自动显示成功/失败对话框
    var result = await saver.SaveWithDialog(_currentImage, _currentFilePath, this);
    
    // result 仍然可用于后续逻辑判断
    if (result.Success)
    {
        // 保存成功后的其他操作（如果需要）
        Log("保存成功");
    }
}
```

### 示例 2：快捷键保存（Ctrl+S）

```csharp
private async void Window_KeyDown(object sender, KeyEventArgs e)
{
    if (e.Key == Key.S && Keyboard.Modifiers == ModifierKeys.Control)
    {
        e.Handled = true;
        
        if (_currentImage != null && !string.IsNullOrEmpty(_currentFilePath))
        {
            var saver = new ImageSaver();
            await saver.SaveWithDialog(_currentImage, _currentFilePath, this);
        }
    }
}
```

### 示例 3：批量保存（显示进度，最后显示总结）

```csharp
private async void BtnBatchSave_Click(object sender, RoutedEventArgs e)
{
    var files = GetFilesToSave(); // 获取要保存的文件列表
    int successCount = 0;
    int failCount = 0;
    
    foreach (var file in files)
    {
        var saver = new ImageSaver();
        
        // 批量保存时使用静默模式（不显示每个文件的对话框）
        var result = await saver.Save(file.Image, file.Path);
        
        if (result.Success)
            successCount++;
        else
            failCount++;
    }
    
    // 最后显示总结
    CustomMessageBox.Show(
        $"批量保存完成！\n\n成功：{successCount} 个\n失败：{failCount} 个",
        "完成",
        CustomMessageBox.MessageBoxButtons.OK,
        CustomMessageBox.MessageBoxType.Information,
        this);
}
```

## 对话框显示的信息

### 成功对话框（SuccessDialog）显示：
1. ✅ **成功标题**：带有绿色勾号
2. 📁 **文件路径**：完整路径，支持长路径自动换行
3. 📊 **文件大小**：自动格式化（B/KB/MB/GB）
4. 📄 **文件格式**：PNG、JPG、DDS 等
5. 🔘 **操作按钮**：
   - 📁 打开文件夹（定位到文件）
   - 📋 复制路径（复制到剪贴板）
   - 关闭

### 错误对话框（CustomMessageBox）显示：
1. ❌ **错误标题**：带有红色错误图标
2. 📝 **错误信息**：具体的错误原因
3. 🔘 **操作按钮**：确定

## 技术细节

### 扩展方法的优势
1. **不修改原有代码**：保持 `ImageSaver` 类的纯粹性（只负责逻辑）
2. **可选使用**：需要UI反馈时用扩展方法，不需要时用原方法
3. **易于维护**：UI相关代码独立在扩展类中
4. **向后兼容**：不影响现有使用 `Save` 方法的代码

### 设计模式
- **扩展方法模式**：为接口添加新功能而不修改接口定义
- **关注点分离**：逻辑层（ImageSaver）和UI层（扩展方法）分离
- **装饰器模式**：在原有功能基础上添加UI显示功能

## 注意事项

1. **父窗口参数**：建议传入父窗口 `owner` 参数，这样对话框会居中显示在父窗口上
2. **异步调用**：使用 `await` 关键字确保保存完成后再显示对话框
3. **异常处理**：扩展方法会自动捕获并显示错误，无需手动处理
4. **批量操作**：批量保存时建议使用原始的 `Save` 方法，最后显示总结对话框
